# 주간 학습 플랜

## 기본 틀

- **분량**: 하루 30분 × 주 5일(월~금).
- **하루 구성**: 10분 요약 카드 읽기 → 10분 대화 예시 따라 말하기 → 10분 퀴즈 또는 롤플레이.
- **기간**: 한 번에 4주(한 단계 분량)를 짠다. 사용자가 원하면 1주나 8주로 짠다.
- **금요일**: 그 주 상품으로 롤플레이 1회를 하고, 이 스킬의 롤플레이 모드를 쓰도록 안내한다.
- **주말 점검(`check`)**: 한 줄로 쓴다. 다음 단계로 가는 기준은 `references/personas.md`의 단계 목표를 따른다.

## 단계별 4주 뼈대

| 단계 | 1주차 | 2주차 | 3주차 | 4주차 |
|---|---|---|---|---|
| Lv1 | 예금·적금 구분(DEP-02, DEP-04) | 중금채는 예금이 아님(DEP-04 vs DEP-05) | 청약·카드 종류(DEP-07, CRD-04) | 방카슈랑스 기초(INS-01) + 6개 총정리 |
| Lv2 | 적금(DEP-01, DEP-02) | 목돈(DEP-03, DEP-04, DEP-05) | 청약 + 카드(DEP-07, CRD-01, CRD-04, CRD-05) | 연금저축보험(INS-01) + 고령 고객 응대 |
| Lv3 | 예금 vs 중금채 비교 | 적금 비교 + 우대금리 계산 | 카드 비교(실적·한도) | 청약 비교 + 타행 비교 응대 |
| Lv4 | 니즈 질문 익히기 | 적금 → 체크카드 동선 | 급여이체 → 주거래 우대, 연금저축 | 거절 대응 + 마무리 화법 |
| Lv5 | 청년·정책 상품(DEP-08, DEP-11) | 재직자·육아(DEP-09, DEP-10) | 연금보험(INS-02, INS-03, INS-06) + 고령 고객 | 복합 상담 롤플레이 + 민원 예방 |

## 진행 방법

1. 사용자의 단계와 시작 주를 확인한다.
   - 사용자가 "이미 아는 상품"이나 "약한 부분"을 말하면 뼈대를 그만큼 조정한다.
2. `kind: "plan"` 내용 JSON을 쓴다(`references/content-schema.md`).
   - `days`의 `todo`에는 상품명과 할 일을 구체적으로 쓴다.
   - 좋은 예: "D-day적금 카드 읽고 우대조건 2개 소리 내어 말하기"
3. `render.py`로 HTML을 만들어 보낸다.
4. 원하면 1주차 교육자료(교육자료 모드)를 바로 이어서 만들어 준다고 제안한다.
