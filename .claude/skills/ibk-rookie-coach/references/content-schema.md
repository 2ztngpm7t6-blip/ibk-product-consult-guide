# 내용 JSON 형식 (`render.py` 입력)

- 상품 사실(금리·조건·보호 여부)은 넣지 않는다. 상품 ID만 넣으면 스크립트가 `data/products.json`에서 채운다.
- Claude가 쓰는 문장 속 % 숫자는 해당 상품 데이터에 있어야 한다. 없으면 경고가 난다.

## material (교육자료)

```json
{
  "kind": "material",
  "level": "Lv2",
  "persona": "한결(가명)",
  "title": "적금 두 가지 확실히 구분하기",
  "intro": "오늘은 창구에서 가장 자주 묻는 적금 두 개를 봅니다.",
  "goals": ["D-day적금과 평생한가족 적금의 차이를 한 문장으로 말하기"],
  "products": ["DEP-01", "DEP-02"],
  "compare": [["DEP-01", "DEP-02"]],
  "compare_notes": {"DEP-01|DEP-02": "D-day적금은 비대면 전용이라 창구에서는 앱 가입을 도와드립니다."},
  "dialogs": [
    {
      "title": "최고금리 받으려면요?",
      "customer": "비교·까다로운 고객",
      "products": ["DEP-01"],
      "lines": [["고객", "최고 4.6% 맞죠?"], ["행원", "기본금리는 12개월 기준 3.1%이고, ..."]],
      "tip": "최고금리보다 기본금리와 우대조건을 먼저 말합니다."
    }
  ],
  "quiz": [{"q": "IBK더굴리기통장(중금채)은 예금자보호 대상인가요?", "a": "아닙니다.", "why": "중소기업금융채권이라 예금자보호 대상이 아닙니다.", "products": ["DEP-05"]}],
  "ask_template": ["정확한 우대조건은 상품설명서로 함께 확인해 드릴게요."]
}
```

## plan (주간 학습 플랜)

```json
{
  "kind": "plan",
  "level": "Lv2",
  "minutes": 30,
  "title": "배치 1개월 차 4주 학습 플랜",
  "intro": "하루 30분, 업무 전후로 진행합니다.",
  "weeks": [
    {
      "week": 1,
      "goal": "적금 두 가지",
      "products": ["DEP-01", "DEP-02"],
      "days": [{"day": "월", "todo": "D-day적금 카드 읽고 우대조건 2개 소리 내어 말하기"}],
      "check": "두 적금의 차이를 1분 안에 설명할 수 있다."
    }
  ]
}
```

## feedback (롤플레이 피드백)

```json
{
  "kind": "feedback",
  "level": "Lv3",
  "persona": "한결(가명)",
  "title": "롤플레이 피드백: 목돈 예치 상담",
  "scenario": "만기 적금 3,000만원을 1년 맡기려는 고객",
  "customer": "48세 회사원(가명 박도윤), 비교·까다로운 고객",
  "products": ["DEP-04", "DEP-05"],
  "scores": {"니즈 파악": 4, "상품 정확성": 3, "설명의무·적합성": 2, "화법·공감": 4, "교차판매·마무리": 3},
  "reasons": {"설명의무·적합성": "중금채의 예금자보호 미대상을 말하지 않음"},
  "critical": ["중금채(DEP-05)를 예금자보호가 된다고 안내함"],
  "good": ["\"기간은 얼마나 생각하세요?\"로 니즈를 먼저 물음"],
  "fix": [{"said": "둘 다 안전해요", "better": "정기예금은 예금자보호 대상이고, 중금채는 채권이라 예금자보호 대상이 아닙니다.", "why": "치명 실수 예방"}],
  "next": "같은 고객으로 다시 해 보고, 이번에는 보호 여부를 먼저 말해 보세요."
}
```

채점 항목 5개는 이름을 정확히 이 순서대로 쓴다: `니즈 파악`, `상품 정확성`, `설명의무·적합성`, `화법·공감`, `교차판매·마무리`.
