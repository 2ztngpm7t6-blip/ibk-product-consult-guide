# 분석 틀

## 1. 기관 유형별로 먼저 볼 것

| 유형 | 신입 페르소나에 영향을 주는 점 |
|---|---|
| 시중은행 | 상품 수가 많고 교차판매 목표가 뚜렷하다. 디지털 전환으로 창구 업무가 복합 상담 위주가 된다. |
| 특수은행(국책·정책금융) | 정책상품과 대상 고객(중소기업·농어업 등) 자격 요건이 많다. 기업금융 비중이 크다. |
| 지방은행 | 지역 고객층(고령·자영업·지역 기업) 비중이 크다. 지자체·지역 정책상품이 있다. |
| 인터넷전문은행 | 창구가 없다. 개인금융 창구 대신 고객센터·운영 직무로 바꿔 분석한다. 앱 화면 기준 안내가 핵심이다. |
| 상호금융·저축은행 | 조합원·지역 기반이다. 예금자보호 체계가 은행과 다르다(각 중앙회 기금 등). 고금리 상품 자격 조건이 다양하다. |

## 2. 데이터 체크리스트: 신입이 실수하기 쉬운 지점 찾기

받은 상품·업무 데이터에서 아래 항목을 세고, 상품 ID와 함께 `findings`에 넣는다. 숫자는 데이터에서 센 값만 쓴다.

**개인금융 창구**
- [ ] **보호 체계가 다른 상품**: 예금자보호 대상이 아니거나 별도 체계인 상품의 수와 목록
  - 예: 채권형, 청약, 보험, 투자상품
  - 같은 브랜드 이름 안에 보호 대상과 비대상이 섞여 있으면 따로 표시한다.
- [ ] **자격 요건 상품**: 나이·소득·재직·무주택·자녀 등 요건이 있는 상품
  - 최고금리가 높은 상품일수록 자격 확인 누락 위험이 크다.
- [ ] **기본금리와 최고금리 차이**: 차이가 큰 상품의 상위 목록
  - 우대조건 질문과 "최고금리만 강조" 실수가 많은 곳이다.
- [ ] **채널 제약**: 비대면 전용이거나 창구에서 가입할 수 없는 상품의 수
- [ ] **카드 실적 기준**: 전월실적 기준이 몇 가지인지, 제외 항목이 카드마다 다른지
- [ ] **투자·보험상품**: 적합성·적정성 확인과 고령자 보호 절차가 필요한 상품의 수
- [ ] **이름이 비슷한 상품 쌍**: 신입이 헷갈리기 쉬운 조합

**기업금융**
- [ ] **여신 상품별 필수 서류 수**: 서류가 많은 상위 상품
- [ ] **정책자금·보증 연계 상품**: 보증기관·지자체 등 외부 기관 절차가 필요한 상품
- [ ] **금리 결정 구조**: 기준금리 종류, 가산금리 요인 수
- [ ] **외환·수출입 업무**: 신고·확인 의무가 있는 업무
- [ ] **구속성 영업 규제와 맞닿는 지점**: 대출과 함께 권하기 쉬운 수신·카드·보험

**민원·오류 통계가 있으면**
- 유형별 건수 상위 5개와 입행 연차별 분포를 본다. 신입 비중이 높은 유형을 찾는다.

## 3. 어려움 맵 영역 (`difficulty_map`)

영역마다 어려움 점수(1~5)와 위험도(높음·중간·낮음)를 정한다.
- 점수는 설문 자신감 문항(6에서 자신감 점수를 뺀 값)이나 "막히는 영역" 선택 비율로 정한다.
- 자료가 없으면 현장의견으로 정하고, 신뢰도가 "추정"이 된다.

| 직무 | 기본 영역 |
|---|---|
| 개인금융 창구 | 상품 지식 / 상담 화법 / 규제·설명의무 / 전산 처리 / 교차판매 / 민원 응대 |
| 기업금융 | 재무제표 분석 / 여신 심사·서류 / 정책자금·보증 / 외환·수출입 / 기업 고객 관계 / 규제(구속성 영업 등) |

- `by_stage`에는 단계별 어려움(1~5)을 넣는다. 히트맵으로 그려진다.
- 모르면 비워 둔다. 지어내지 않는다.

**어려움 점수 계산법.** 은행끼리 비교할 수 있도록 같은 식을 쓴다.

| 있는 자료 | 점수 |
|---|---|
| "막히는 영역" 선택 비율 r(0~1) | 선택 점수 = 1 + 4 × r |
| 같은 영역의 자신감 평균 c(1~5) | 자신감 점수 = 6 − c |
| 둘 다 있음 | 두 점수의 평균, 소수 첫째 자리 |
| 하나만 있음 | 있는 점수 |
| 둘 다 없음 | 현장의견으로 정하고 `note`에 "현장의견 기준"이라고 쓴다 |

- `note`에는 계산에 쓴 숫자를 적는다. 예: "선택 7/10명, 자신감 2.3"
- 신입이 "막힌다"고 고르지 않았는데, 걱정되는 실수나 선배 의견에서 위험이 크게 나오는 경우가 있다.
  - 이런 영역은 점수를 올리지 않는다. 점수는 그대로 두고 `risk`를 높이고 `conflict`에 차이를 적는다.
  - 신입이 위험을 과소평가하고 있다는 신호이기 때문이다.

## 4. 성장 5단계 기본틀

그 은행의 연수·배치 일정에 맞춰 시점과 이름을 바꾼다.

| 단계 | 기본 시점 | 개인금융 창구 초점 | 기업금융 초점 |
|---|---|---|---|
| Lv1 | 입행 1주(연수) | 상품 종류와 보호 체계 구분 | 기업 상품 종류, 재무제표 기초 |
| Lv2 | 배치 1개월 | 빈출 상품 핵심 숫자, 설명의무, 기본 화법 | 수신·급여이체 등 기업 수신 업무, 서류 목록 |
| Lv3 | 3개월 | 헷갈리는 상품 비교, 거절 대응 | 운전자금 여신 서류와 심사 흐름 |
| Lv4 | 6개월 | 니즈 발굴과 교차판매 | 정책자금·보증, 외환 기초 |
| Lv5 | 1년 | 복합 상담, 취약 고객, 민원 예방 | 신규 기업 발굴, 복합 금융 제안, 규제 준수 |

## 5. 교육 제안 (`proposals`)

- 어려움 맵에서 **어려움이 크고 위험도도 높은** 영역부터 우선순위를 매긴다.
- 제안마다 대상 단계, 해결할 니즈, 형식(요약 카드·비교표·롤플레이·사례 토론·멘토링 등)을 적는다.
  - 형식은 설문의 학습 선호와 하루 학습 시간에 맞춘다.
- 근거 출처를 단다. 근거가 현장의견뿐이면 "파일럿 후 검증"을 함께 제안한다.
