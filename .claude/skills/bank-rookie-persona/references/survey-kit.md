# 설문·인터뷰 키트

설문 자료가 없을 때 이 키트로 설문지와 인터뷰 질문지를 만들어 준다.

- 은행 이름, 직무, 단계 이름은 1라운드 답에 맞춰 바꾼다.
- 문항 수는 신입 설문 15문항 이내(5분), 선배 인터뷰 10문항 이내(20분)로 한다.

## 설문 안내문 (설문지 맨 앞에 넣는다)

> 이 설문은 신입행원 교육을 개선하기 위한 것입니다. 이름·사번·연락처는 묻지 않으며, 결과는 5명 이상 모인 집계로만 사용합니다. 답하기 싫은 문항은 건너뛰어도 됩니다.

## 신입행원 설문 (기본형)

결과는 `scripts/survey_summary.py`가 읽을 수 있게 CSV로 받는다.
- 첫 줄은 문항 제목, 한 줄은 응답자 한 명이다.
- 복수 선택 응답은 `;`로 구분한다.

| # | 문항 | 형식 |
|---|---|---|
| 1 | 입행 후 경과 기간 | 단일: 1개월 미만 / 1~3개월 / 3~6개월 / 6개월~1년 / 1년 이상 |
| 2 | 현재 직무 | 단일: 개인금융 창구 / 기업금융 / 기타 |
| 3 | 전공 계열 | 단일: 상경 / 비상경 |
| 4 | 입행 전 금융권 경험 | 복수: 없음 / 은행 인턴 / 타 금융권 근무 / 금융 관련 대외활동 |
| 5 | 업무 중 가장 막히는 영역(최대 3개) | 복수: 상품 지식 / 상담 화법 / 규제·설명의무 / 전산 처리 / 서류·심사 / 교차판매 / 민원 응대 |
| 6 | 상품 지식 자신감 | 척도 1~5 |
| 7 | 고객 응대 자신감 | 척도 1~5 |
| 8 | 규제(설명의무·적합성) 이해 자신감 | 척도 1~5 |
| 9 | 가장 자주 받는 고객 질문 | 복수: 금리 비교 / 우대조건·중도해지 / 카드 혜택 / 정책상품 자격 / 대출 한도·서류 / 외환 / 기업 자금 |
| 10 | 실수할까 가장 걱정되는 것 | 복수: 상품 오안내 / 자격 확인 누락 / 서류 누락 / 고령 고객 응대 / 실적 압박 속 권유 |
| 11 | 심리적 부담 | 복수: 실수·민원 두려움 / 선배에게 묻는 눈치 / 응대 긴장 / 실적 압박 / 전산 미숙 |
| 12 | 선호하는 학습 방식(최대 2개) | 복수: 요약 카드 / 비교표 / 대화 예시 / 퀴즈 / 롤플레이 / 사례 토론 / 영상 |
| 13 | 하루 학습 가능 시간 | 단일: 10분 / 15분 / 30분 / 1시간 이상 |
| 14 | 가장 도움이 된 교육·도움 | 자유응답 |
| 15 | 입행 첫 달에 있었으면 좋았을 것 | 자유응답 |

**기업금융 추가 문항** (직무가 기업금융이면 5·9번 선택지에 더해 넣는다)
- 재무제표 읽기 자신감(척도 1~5)
- 여신 심사 서류 이해 자신감(척도 1~5)
- 가장 어려운 기업 상품: 운전자금 / 시설자금 / 정책자금·보증서 / 외환·수출입 / 기업 수신

## 선배·멘토 인터뷰 질문지

1. 최근 1~2년 신입 중 "잘 큰 사람"과 "힘들어한 사람"은 무엇이 달랐나요? (개인이 특정되지 않게)
2. 신입이 배치 첫 달에 가장 자주 묻는 것은 무엇인가요?
3. 신입이 실제로 낸 실수 중 고객 피해·민원으로 이어질 뻔한 유형은 무엇인가요?
4. 이 은행 상품 중 신입이 특히 헷갈려하는 조합이 있나요?
5. 신입에게 처음 가르칠 때 순서를 어떻게 잡나요?
6. 단계마다 "이제 혼자 해도 되겠다"고 판단하는 기준은 무엇인가요?
7. 신입이 선배에게 묻기 어려워하는 주제가 있나요?
8. 연수 내용 중 현장과 다른 것은 무엇인가요?
9. 지역·지점 유형에 따라 신입이 겪는 차이가 있나요?
10. 신입 교육에 하나만 바꿀 수 있다면 무엇을 바꾸겠나요?

인터뷰 메모를 받으면 `anonymize.py`로 가명화한다. 그다음 답마다 출처 `현장의견`(인터뷰 n번)으로 기록한다.
