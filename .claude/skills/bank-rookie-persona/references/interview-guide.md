# 담당자·선배 문답 가이드

- 문답은 라운드마다 질문 2~4개로 진행한다. 선택지가 있으면 선택형으로 묻고, "기타"로 자유롭게 답할 수 있게 한다.
- 답은 그때그때 `persona.json`의 `sources`에 `현장의견`으로 기록한다.
  - 예: `{"id":"F1","type":"현장의견","title":"연수 담당자 문답","detail":"2라운드, 인사부 과장급"}`
- 매 라운드가 끝나면 지금까지의 페르소나 초안을 5줄 이내로 보여 주고 다음 라운드로 간다.

## 1라운드: 기본 정보

| 질문 | 왜 묻나 |
|---|---|
| 은행 이름과 기관 유형(시중·특수·지방·인터넷전문·상호금융·저축은행) | 고객층·채널·상품군이 달라진다 |
| 직무: 개인금융 창구 / 기업금융 / 둘 다 | 페르소나를 직무별로 따로 만든다 |
| 연수 제도: 집합연수 기간, 첫 배치 시점, 멘토링·OJT 유무 | 5단계의 시점과 이름을 맞춘다 |
| 분석 범위: 입행 연도, 지역, 지점 유형(도심·주거지·산업단지 등) | 범위가 다르면 페르소나가 달라진다 |

## 2라운드: 신입의 출발점

- 주로 어떤 배경으로 들어오나요?
  - 상경계 / 비상경 / 인턴·체험형 경험 / 타 금융권 경력 / 지역 인재
- 입행 때 이미 알고 있는 것과 전혀 모르는 것은 무엇인가요?
  - 금융 이론, 상품, 전산, 규제
- 자격증은 보통 어느 정도 갖고 들어오나요?
  - 펀드·보험·외환·여신 관련. 해당 은행 요구 수준을 묻는다.
- 신입이 학습에 쓸 수 있는 시간은 하루 얼마인가요?

## 3라운드: 막히는 곳과 위험한 실수

**개인금융 창구**
- 고객에게 가장 자주 받는 질문 유형
  - 금리 비교, 우대조건·중도해지, 카드 실적, 청약·정책상품 자격, 대출 한도·서류
- 저지르면 가장 위험한 실수
  - 예금자보호 오안내, 자격 확인 누락, 고령자·취약 고객 부적합 권유, 대출 서류 누락, 최고금리만 강조
- 교차판매·실적 목표가 신입에게 주는 부담

**기업금융**
- 기업 고객이 자주 묻는 것
  - 운전자금·시설자금 한도, 정책자금·보증서, 외환·수출입, 기업 수신·급여이체
- 위험한 실수
  - 심사 서류 누락, 보증·담보 조건 오안내, 구속성 영업(꺾기) 의심 행위, 외환 신고 누락
- 재무제표·기업 정보를 읽는 수준

## 4라운드: 마음과 배우는 방식

- 가장 큰 심리적 부담
  - 실수·민원 두려움, 선배에게 묻는 눈치, 응대 긴장, 실적 압박, 전산 미숙
- 선호하는 학습 방식
  - 요약 카드, 비교표, 대화 예시, 퀴즈, 롤플레이, 사례 토론
- 선배가 보기에 "잘 크는 신입"과 "힘들어하는 신입"의 차이
- 단계별로 "이 정도면 다음 단계"라고 판단하는 기준

## 검토 라운드 (보고서를 보여 준 뒤)

- 현장 감각과 다른 내용이 있나요? 어느 항목인가요?
- 빠진 페르소나 특성이나 단계가 있나요?
- 신뢰도가 "추정"인 항목 중 자료로 확인할 수 있는 것이 있나요?
- 교육 제안의 우선순위가 맞나요?
