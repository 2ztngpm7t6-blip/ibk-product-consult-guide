# IBK 상품 영업 AI 에이전트 (v0.1)

IBK기업은행의 예적금·카드·방카슈랑스 상품으로 **직원 교육 / 고객 안내 / 창구 영업**을 돕고,
대화 내용으로 **제안서·보고서를 자동 작성**하는 Claude 기반 교육·연습용 프로그램입니다.

## API 키 없이 쓰는 IBK 상품 상담 가이드 (`IBK_상품상담가이드.html`)

파일을 더블클릭하면 브라우저에서 바로 열립니다(인터넷·설치·API 키 불필요).
상품 하나를 고르면 **같은 상품 기준으로 보고서 3종**이 자동으로 만들어집니다.

| 보고서 | 들어가는 내용 |
|---|---|
| 🎓 직원 교육용 | 상품 구조 표, 금리·혜택 그래프, 같은 종류 상품 비교, 판매 포인트·설명의무, 퀴즈, 롤플레이 설정 |
| 🙋 고객 안내용 | 핵심 숫자 카드, 이런 분께 맞아요, 내 이자·혜택·세액공제 계산기, 가입 전 주의사항 |
| 💼 창구 영업용 | 고객 프로필 입력 → 적합성 판단(✅⚠️❌), 예상 이자·혜택, 상담 화법, 교차판매, 6대 판매원칙 점검표, 메모 |

- AI 대신 규칙 기반으로 만들기 때문에 `data/products.json`에 있는 사실만 나옵니다.
- [PDF 저장] 버튼 → 인쇄 창에서 "PDF로 저장"을 고르면 됩니다. 3종을 한 번에 저장할 수도 있습니다.
- 상품 정보를 고치면 `sh report-studio/build.sh`로 다시 만듭니다(화면 코드는 `report-studio/template.html`).

## 세 가지 페르소나 (Claude API 버전, `app.py`)

| 모드 | 대상 | 하는 일 |
|---|---|---|
| 🎓 직원 교육용 코치 | 신입·인턴 행원 | 상품 공부, 퀴즈, AI가 연기하는 고객과 롤플레이, 5개 기준 피드백 |
| 🙋 고객 안내 도우미 | 고객 | 쉬운 말로 설명, 니즈 확인 후 2~3개 안내, 판매 압박 없음 |
| 💼 창구 영업 어시스턴트 | 창구 직원 | 고객 프로필 → 추천 상품·교차판매·화법·설명의무 체크리스트 |

## 자동 보고서 (HTML → 브라우저에서 Ctrl+P로 PDF 저장)

- **고객 제안서**: 고객 상황 요약, 추천 상품(근거·핵심조건·주의사항), 가입 전 확인사항
- **상담·영업 보고서(내부용)**: 상담 요약, 니즈, 제안 상품, 금소법 판매원칙 이행 점검표, 후속 조치
- **교육 결과 보고서**: 5개 기준 점수, 잘한 점·보완점, 추천 학습

`examples/` 폴더에 샘플 보고서가 있습니다(가짜 데이터로 만든 견본).

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 열리면 왼쪽에 Claude API 키를 입력하세요(또는 `ANTHROPIC_API_KEY` 환경변수를 설정).
API 키는 https://console.anthropic.com 에서 발급합니다. 키는 화면에만 보관되고 파일로 저장되지 않습니다.

## 구조

```
app.py               Streamlit 화면 (모드 선택, 채팅, 고객 프로필, 보고서)
agent/catalog.py     data/products.json 로드
agent/prompts.py     페르소나별 시스템 프롬프트 + 공통 원칙(금소법 6대 원칙 등)
agent/llm.py         Claude API 호출 (스트리밍, 구조화 출력, 거절 시 자동 대체 모델)
agent/reports.py     보고서 스키마 → HTML 렌더링
data/products.json   상품 카탈로그 (25개)
```

- 모델: `claude-opus-5-5` (채팅 effort=medium, 보고서 effort=high)
- 상품 카탈로그는 시스템 프롬프트에 넣고 프롬프트 캐시를 걸어 두 번째 요청부터 비용을 줄입니다.
- AI가 카탈로그에 없는 내용을 지어내지 않도록 상품 id(예: DEP-01)를 붙여 말하게 하고, 보고서에 근거 자료(상품설명서 번호·공식 페이지 링크)를 자동으로 붙입니다.

## 상품 데이터

- 출처: IBK기업은행 공식 홈페이지 상품 상세 페이지, **2026-11-06 확인**
- 예적금 11개, 카드 8개, 보험(방카슈랑스) 6개 (개인 고객용 대표 상품, 전체 상품이 아님)
- 보험은 홈페이지에 요약만 있고 보장 상세는 PDF(상품안내장)에 있어서, AI가 보장 수치를 말하지 않도록 막아 두었습니다.
- 금리·혜택은 바뀝니다. 주택청약종합저축 설명서는 2026-11-10에 유효기간이 끝나니 새 설명서로 갱신이 필요합니다.

## 주의

- 교육·연습용 시뮬레이션이며 실제 가입 권유나 금융 자문이 아닙니다.
- 실제 고객의 실명·주민번호·계좌번호를 입력하지 마세요(가명 사용).
