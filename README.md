# IBK 상품 상담 가이드

IBK기업은행 개인 고객용 대표 상품 25개로 **직원 교육용 · 고객 안내용 · 창구 영업용** 보고서를 같은 상품 기준으로 자동으로 만들어 주는 교육·연습용 도구입니다.

- 파일 하나(`IBK_상품상담가이드.html`)를 브라우저로 열면 바로 쓸 수 있습니다. 설치, 서버, API 키가 필요 없습니다.
- AI가 문장을 지어내지 않습니다. 공식 홈페이지에서 확인한 상품 정보만 규칙에 따라 조합합니다.

> 개인이 만든 교육·연습용 자료입니다. IBK기업은행의 공식 자료나 금융 자문이 아니며, 로고 상표는 IBK기업은행 소유입니다.

## 사용 방법

1. `IBK_상품상담가이드.html`을 더블클릭해 브라우저로 엽니다.
2. 왼쪽에서 상품을 고릅니다(전체 / 예적금 / 카드 / 보험).
3. 위쪽 탭에서 보고서 종류를 바꿔 봅니다.
4. **[이 보고서 PDF 저장/인쇄]** 또는 **[보고서 3종 한 번에 PDF]**를 누르고, 인쇄 창에서 "PDF로 저장"을 고릅니다.

### 창구 영업용 주요 기능

- **고객 유형 프리셋 7종**: 대학생·인턴, 사회초년생, 결혼 준비, 맞벌이 가정, 자영업자, 은퇴 고객, 여행 좋아하는 직장인
- **이 고객에게 맞는 상품 순위**: 고객 니즈·금액·성향으로 상위 5개를 추천합니다.
- **[이 상품으로 전환]**: 고객 정보는 그대로 두고 보고서 3종을 다른 상품 기준으로 바꿉니다. 전환 전후 비교표와 [이전 상품으로 돌아가기] 버튼이 나옵니다.
- **적합성 판단**: 니즈 일치, 가입 금액·기간, 예금자보호, 카드 전월실적, 청년·중소기업 재직자 전용 요건, 비대면 전용 여부를 항목별로 표시합니다.

## 신입행원 코치 스킬 (Claude Code)

이 가이드는 IBK기업은행에 새로 들어온 신입행원을 돕기 위해 만들었습니다.

- 신입행원 페르소나를 문답으로 다듬고 분석한 내용은 [`docs/신입행원_페르소나_분석.md`](docs/신입행원_페르소나_분석.md)에 있습니다.
- 그 분석을 자동화한 Claude Code 스킬이 `.claude/skills/ibk-rookie-coach/`에 있습니다.

이 폴더에서 Claude Code를 열고 아래처럼 요청하면 됩니다.

| 모드 | 요청 예 | 결과 |
|---|---|---|
| 교육자료 | "Lv3용 더굴리기통장 예금 vs 중금채 자료 만들어줘" | 요약 카드·비교표·대화 예시·퀴즈 HTML |
| 롤플레이 | "까다로운 고객으로 상담 연습하자" | Claude가 가상 고객 역할 → 항목별 점수·개선 화법 HTML |
| 학습 플랜 | "배치 1개월 차 4주 플랜 짜줘" | 하루 30분 × 주 5일 플랜 HTML |
| 가이드 업데이트 | "D-day적금 금리 바뀌었어" | 공식 페이지 재확인 → `products.json` 수정 → 가이드 재빌드 |

- 성장 단계는 Lv1(입행 1주)부터 Lv5(1년)까지 5단계입니다.
- 금리·조건 숫자는 스크립트가 `data/products.json`에서 직접 넣습니다. Claude가 쓴 문장 속 숫자가 데이터에 없으면 경고합니다.
- 샘플 결과물은 `docs/samples/`에 있습니다.

### 은행 공통 페르소나 분석 스킬

`.claude/skills/bank-rookie-persona/`에는 IBK가 아닌 은행에서도 쓸 수 있도록 일반화한 **신입행원 페르소나 분석 스킬**이 함께 들어 있습니다.

- 담당자·선배와 문답하며 상품 데이터·설문·공개 자료를 근거로 페르소나 보고서(HTML)를 만듭니다.
- 모든 항목에 출처와 신뢰도를 표시합니다.
- 설문 원자료는 자동으로 가명화합니다.
- 별도 저장소: [bank-rookie-persona](https://github.com/2ztngpm7t6-blip/bank-rookie-persona) (사용법과 가상 은행 예시 포함)

## 파일 구성

```
IBK_상품상담가이드.html        완성본(이 파일 하나만 있으면 됨)
docs/                          신입행원 페르소나 분석, 스킬 샘플 결과물
.claude/skills/ibk-rookie-coach/  신입행원 코치 스킬(SKILL.md, 참고 문서, render.py)
.claude/skills/bank-rookie-persona/  은행 공통 신입행원 페르소나 분석 스킬
data/products.json             상품 데이터 25개(공식 홈페이지 확인 내용)
report-studio/template.html    화면·보고서 템플릿(규칙·계산기·화법 포함)
report-studio/assets/logo.b64  로고 이미지 데이터(흰 배경 제거)
report-studio/build.sh         데이터와 로고를 템플릿에 넣어 완성본을 만드는 스크립트
```
